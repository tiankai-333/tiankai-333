# Hi, I'm Tucker Wu (@tiankai-333) 👋

AI 对话系统 / 游戏工程。关注点：让模型在受控边界内扮演有知识、有秘密的角色，并把"生成"与"业务执行"分开。

## 精选项目

### [storycraft-game](https://github.com/tiankai-333/storycraft-game) — 主维护仓库

两部分：

- **[@wutiankai/npc-dialogue](https://www.npmjs.com/package/@wutiankai/npc-dialogue)** — 可复用的 AI NPC 对话引擎 npm 包：角色知识与信任分层、话题门控审查、多轮上下文、双语关键词匹配、OpenAI 兼容模型适配。包只产出回复文本与候选信号，业务状态由宿主应用校验执行——该管线结构可迁移到客服机器人等对话场景。
- **StoryCraft 推理游戏** — 上述对话包的实际应用与验证场：暴风雪庄园谜案，浏览器 / 终端双模式，多结局。网页版迁移部署中（新入口：<http://game.wutiankai.cn>，尚未上线），本地运行见仓库 README。

> UI/部署迭代的历史协作仓库：[baodashuaige/StoryCraft](https://github.com/baodashuaige/StoryCraft)（内容已同步回本仓库）。
